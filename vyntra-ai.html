What is Vyntra AI?

A portfolio project that combines AI, cloud services, authentication, database access control and live web search.

Personal AI Assistant

Vyntra AI is designed as an intelligent interface for Ezhilarasan's portfolio. Instead of manually searching different pages, visitors can ask questions and interact with the assistant to learn about the developer, projects, certifications, technologies and career focus.

Controlled Access

User access is controlled through Google OAuth and a Cloudflare D1 database. New users can enter a pending state before being approved for AI chat access.

Key Features

AI-Powered Chat

Natural-language conversations powered by the Google Gemini API through a backend Worker.

Live Web Search

Tavily search can retrieve current web information and return source titles and links with answers.

Google Sign-In

Google OAuth 2.0 is used to authenticate users before access is checked.

Access Approval

Users can be stored as pending, approved or denied through the access-control workflow.

Conversation History

Recent user and assistant messages are maintained to provide conversational context.

Markdown Responses

AI responses can be rendered with Markdown formatting for cleaner technical explanations.

How It Works

From user authentication to AI response.

01

Google Sign-In

The visitor signs in using Google OAuth.

02

Access Check

The Worker checks the user's access status through the D1 database.

03

Ask Vyntra AI

Approved users can send questions to the Vyntra AI backend.

04

Live Search

When current information is required, Tavily can provide web results.

05

Gemini Response

The backend sends the relevant context to Gemini and receives the AI response.

06

Answer + Sources

The frontend displays the response with Markdown formatting and available sources.
